# ApexGold — בוט מסחר 1:3 למטה טריידר 5

בוט מסחר ל־MetaTrader 5 שבנוי סביב יחס סיכוי־סיכון קבוע של 1:3, מיועד
ל־XAUUSD אבל עובד על כל צמד. יחד איתו מגיעה סביבת מחקר בפייתון שמאפשרת
לבדוק את האסטרטגיה על הנתונים של הברוקר שלך לפני שנוגעים בכסף.

---

## קודם כול, בכנות

**אי אפשר להבטיח שבוט יהיה רווחי, וזה כולל את הבוט הזה.** אם מישהו מבטיח
לך את זה, הוא מוכר לך תוצאות עבר או שיטת מרטינגייל שמוחקת חשבונות.

מה שיש כאן הוא שלושה דברים שאפשר להבטיח:

1. **היגיון מוגדר וניתן לבדיקה.** כל כלל כתוב, מתועד, ומיושם פעמיים —
   ב־MQL5 לריצה חיה, ובפייתון לבדיקה. שתי הגרסאות אמורות להסכים.
2. **שכבת הגנה על ההון שלא ניתן לעקוף.** סיכון לעסקה, הפסד יומי, הפסד
   שבועי, ירידה מהשיא, רצף הפסדים, מסנן מרווח ומסנן חדשות.
3. **כלים לבדוק אם יש כאן יתרון.** בקטסט עם עלויות אמיתיות, walk-forward
   מחוץ למדגם, ומונטה קרלו — כולל בדיקה אוטומטית שאין הצצה לעתיד.

השאלה "האם זה רווחי" נענית בשלב 2 עד 5 בטבלה ב־[docs/SETUP.md](docs/SETUP.md),
על הנתונים שלך, אצל הברוקר שלך. לא כאן.

## מה הבוט עושה

הבוט מסווג קודם את מצב השוק ורק אחר כך מחליט איזו משפחת סטאפ רלוונטית:

- **חזרה לאזור ערך במגמה** — כשיש מגמה ברורה בטווח זמן גבוה, ומחיר חוזר
  לאזור הממוצעים אחרי שהמבנה כבר נשבר בכיוון המגמה.
- **סחיפת טווח אסיה** — כשלונדון חוטפת את קצה הטווח הלילי, נכשלת, וחוזרת
  פנימה. הסטופ יושב מיד מעבר לנקודת הסחיפה ולכן הוא קצר.
- **פריצה מדחיסת תנודתיות** — כשהטווח מתכווץ ואז נשבר בנר בעל גוף משמעותי.

כל מועמד מקבל **ניקוד קונפלואנס** בין 0 ל־100 לפי התאמה לטווח זמן גבוה,
משטר שוק, מצב תנודתיות, שעת מסחר, מומנטום, ומרחק פנוי עד היעד. רק ניקוד
מעל הסף מייצר עסקה. הסטופ נגזר ממבנה השוק עם כרית ATR, והיעד תמיד בדיוק
פי שלושה מהסיכון.

הרציונל המלא, כולל כל המשפחות שנבחנו ונפסלו — גריד, מרטינגייל, חזרה לממוצע,
מסחר חדשות ולמידת מכונה — נמצא ב־[docs/STRATEGY.md](docs/STRATEGY.md).

## התחלה מהירה

### הרצת סביבת המחקר

```bash
cd mt5-gold-bot/research
pip install -r requirements.txt

python selftest.py                            # 19 בדיקות תקינות
python run_backtest.py --synthetic --bars 30000   # בדיקת צנרת
```

בקטסט על הנתונים שלך, אחרי ייצוא M15 מהטרמינל:

```bash
python run_backtest.py --csv XAUUSD_M15.csv --broker-gmt-offset 2 \
    --spread-points 25 --commission 7 --risk 0.5

python run_backtest.py --csv XAUUSD_M15.csv --broker-gmt-offset 2 --walk-forward
```

### התקנת הבוט

העתק את `MQL5/` לתוך תיקיית הנתונים של הטרמינל, קמפל ב־MetaEditor, וגרור
על גרף `XAUUSD M15`. הוראות מלאות ב־[docs/SETUP.md](docs/SETUP.md).

**שתי הגדרות שחייבים לבדוק לפני הרצה:**

| פרמטר | למה |
|---|---|
| `InpGmtOffsetHours` | אם השעון לא נכון, כל מסנני המושבים עובדים על השעות הלא נכונות |
| `InpMaxSpreadPoints` | פיד עם 3 ספרות מציג מרווח פי 10, והבוט פשוט לא ייכנס |

## מה נבדק ומה עבר

`selftest.py` מריץ 19 בדיקות. הן קיימות כי אלה בדיוק הדברים שהופכים בקטסט
לאשליה:

| קבוצה | מה נבדק |
|---|---|
| אינדיקטורים | התאמה להחלקת Wilder של MetaTrader, ונקודות תנודה שמדווחות באיחור |
| **הצצה לעתיד** | האותות לא משתנים כשמוחקים את הנרות העתידיים מהנתונים |
| עלויות | עסקה שנעצרה מפסידה קצת יותר מ־1R, ועסקה שהגיעה ליעד מרוויחה קצת פחות מ־3R |
| גודל פוזיציה | הסיכון בפועל תואם את האחוז שהוגדר |
| נר דו־משמעי | נר שנגע גם בסטופ וגם ביעד נספר כהפסד, לא כרווח |
| שכבת סיכון | תקרת עסקאות יומית ועצירת ירידה מהשיא באמת עוצרות |

בהרצה על נתונים מלאכותיים חסרי יתרון אמיתי, המנוע מחזיר תוצאה של בערך אפס
עם 34 אחוז הצלחה. זה הסימן החשוב ביותר לתקינות: **המנוע לא ממציא רווח
במקום שאין בו יתרון.**
