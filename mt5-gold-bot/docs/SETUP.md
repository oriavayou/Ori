# התקנה, בדיקה והרצה

## 1. התקנת ה־Expert Advisor במטה טריידר 5

1. בטרמינל: `File` → `Open Data Folder`. נפתחת תיקייה שבתוכה יש `MQL5`.
2. העתק את התוכן של `mt5-gold-bot/MQL5` לתוך תיקיית `MQL5` של הטרמינל, כך ש:
   - `MQL5/Experts/ApexGold/ApexGoldEA.mq5`
   - `MQL5/Include/ApexGold/*.mqh`
3. פתח את MetaEditor (`F4`), בחר את `ApexGoldEA.mq5`, ולחץ `Compile` (`F7`).
   הקומפילציה צריכה לעבור בלי שגיאות. אזהרות על המרות טיפוס הן תקינות.
4. בטרמינל, ב־Navigator, לחץ ימני על `Expert Advisors` ובחר `Refresh`.
5. גרור את `ApexGoldEA` על גרף `XAUUSD` בטווח זמן `M15`.

### הגדרה קריטית אחת שחייבים לבדוק: היסט השעון

כל חוקי המושבים בבוט מחושבים לפי GMT. הפרמטר `InpGmtOffsetHours` אומר לבוט
בכמה שעות שעון השרת של הברוקר מקדים את GMT.

איך בודקים: פתח `Market Watch`, הסתכל על השעה שהטרמינל מציג ליד הציטוט,
והשווה לשעת GMT הנוכחית. ההפרש הוא הערך שצריך להזין. אצל רוב הברוקרים
האירופיים זה 2 בחורף ו־3 בקיץ. אם הערך שגוי, כל מסנני המושבים יעבדו על
השעות הלא נכונות והבוט יסחור בזמנים הגרועים ביותר.

### מספר עשרוני ונקודות

לפני הרצה בדוק את ערך `InpMaxSpreadPoints` מול הברוקר שלך:
- פיד זהב עם 2 ספרות אחרי הנקודה: מרווח טיפוסי 20 עד 40 נקודות
- פיד זהב עם 3 ספרות: אותו מרווח מוצג כ־200 עד 400 נקודות

אם הערך נמוך מדי, הבוט פשוט לא יפתח עסקאות. הפאנל על הגרף מציג את המרווח
הנוכחי בנקודות, אז אפשר לראות ישירות מה המספר הנכון.

## 2. בדיקה ב־Strategy Tester

1. `View` → `Strategy Tester` (`Ctrl+R`).
2. Expert: `ApexGold\ApexGoldEA`, Symbol: `XAUUSD`, Period: `M15`.
3. Model: **Every tick based on real ticks**. שום דבר אחר לא אמין לבוט
   שמשתמש בסטופ ובלימיט באותה עסקה, כי מודלים מהירים יותר לא יודעים באיזה
   סדר נגעו בשתי הרמות בתוך אותו נר.
4. תקופה: לפחות שלוש שנים. בזהב חובה לכלול גם 2022 וגם 2024, שני משטרים שונים לגמרי.
5. Deposit: סכום שדומה לחשבון האמיתי שלך. עם 500 דולר וסיכון 0.5 אחוז,
   חלק מהאותות ידחו כי גודל הלוט המחושב קטן מהמינימום של הברוקר.

### אופטימיזציה בלי להרוס את הבוט

- **אל תריץ אופטימיזציה על כל הפרמטרים.** זו הדרך המהירה ביותר להתאמת יתר.
- מקסימום שלושה פרמטרים בכל סבב. המועמדים הסבירים: `InpMinScore`,
  `InpMaxStopAtrMult`, `InpAdxTrendMin`.
- בחר `Custom max` כקריטריון. הפונקציה `OnTester` בקוד מחזירה רווח ליחידת
  ירידה מהשיא, מוכפל בפקטור רווח ומדוכא לפי מספר עסקאות. היא מחזירה אפס
  לכל הרצה עם פחות מ־40 עסקאות, כדי שלא תיבחר הרצה שהצליחה במקרה.
- אחרי האופטימיזציה, הרץ את הפרמטרים הנבחרים על **תקופה שלא השתתפה
  באופטימיזציה**. אם התוצאה שם נראית אחרת לגמרי, מצאת התאמת יתר ולא אסטרטגיה.

## 3. סביבת המחקר בפייתון

```bash
cd mt5-gold-bot/research
pip install -r requirements.txt
python selftest.py
```

`selftest.py` בודק את הדברים ששוברים בקטסטים בשקט: הצצה לעתיד, חישוב עלויות,
גודל פוזיציה, וטיפול בנר שנגע גם בסטופ וגם ביעד. כל 19 הבדיקות חייבות לעבור.

### הרצה על נתונים אמיתיים

ייצוא הנתונים מהטרמינל: `Tools` → `Options` → `Charts` → הגדל את
`Max bars in chart`, ואז בגרף `XAUUSD M15` לחץ `Ctrl+S` ושמור כקובץ CSV.

```bash
python run_backtest.py --csv XAUUSD_M15.csv --broker-gmt-offset 2 \
    --spread-points 25 --commission 7 --risk 0.5 --save-trades trades.csv
```

בדיקת יציבות מלאה:

```bash
python run_backtest.py --csv XAUUSD_M15.csv --broker-gmt-offset 2 --walk-forward
```

ה־walk-forward מכייל את הפרמטרים על העבר בלבד ומודד על תקופה שלא נראתה.
הוא מדווח **רק** תוצאות מחוץ למדגם. אם התוצאה מחוץ למדגם שלילית, הפרמטרים
לא שרדו את המבחן, ואין טעם להריץ את זה על כסף.

## 4. סדר העבודה לפני כסף אמיתי

| שלב | מה בודקים | מתי ממשיכים |
|---|---|---|
| 1. בדיקה עצמית | `python selftest.py` | 19 מתוך 19 עוברות |
| 2. בקטסט היסטורי | 3 שנים ומעלה, real ticks | תוחלת חיובית אחרי עלויות |
| 3. walk-forward | תוצאה מחוץ למדגם | תוחלת חיובית גם שם |
| 4. מונטה קרלו | סדר העסקאות מעורבב | הסתברות ההפסד המקסימלית נסבלת |
| 5. דמו | **שלושה חודשים לפחות** | התוצאה דומה לבקטסט |
| 6. אמיתי בקטן | 0.25 אחוז סיכון | שלושה חודשים נוספים |

שלב 5 הוא זה שאנשים מדלגים עליו, והוא היחיד שבודק את מה שבקטסט לא יכול
לבדוק: איך הברוקר שלך באמת ממלא פקודות.

## 5. פרופ פירם

אם אתה סוחר בחשבון מימון, שנה את ההגדרות הבאות:

```
InpRiskValue          = 0.25
InpDailyLossLimitPct  = 2.0      נמוך מהגבול של החברה
InpMaxDrawdownPct     = 6.0      נמוך מגבול ה־drawdown הכולל
InpMaxTradesPerDay    = 2
InpFridayCloseHourGmt = 16       חלק מהחברות אוסרות החזקה בסוף שבוע
InpUseNewsFilter      = true
```

הכלל הוא להגדיר את הגבולות של הבוט **מתחת** לגבולות של החברה, כי הבוט מודד
את עצמו לפי יתרה ולא לפי ההגדרה המדויקת של החברה.

## 6. בדיקת התאמה בין הבוט לסימולציה

שתי המימושים אמורים להסכים. אם הם לא, אחד מהם משקר.

1. הפעל את הבוט ב־Strategy Tester על תקופה מוגדרת עם `InpLogToFile=true`.
   נוצר קובץ CSV תחת `MQL5/Files` עם כל כניסה, ניקוד, וסיבה.
2. הרץ את אותה תקופה בפייתון עם אותם פרמטרים ואותן עלויות:

```bash
python run_backtest.py --csv XAUUSD_M15.csv --broker-gmt-offset 2 \
    --spread-points <המרווח הממוצע מהבקטסט> --commission <העמלה שלך> \
    --save-trades python_trades.csv
```

3. השווה את מספר העסקאות ואת אחוז ההצלחה. הפרש קטן הוא נורמלי: הבוט מקבל
   מרווח משתנה מהנתונים ההיסטוריים בעוד שהסימולציה מניחה מרווח קבוע, והוא
   רואה טיקים בעוד שהסימולציה רואה נרות. **הפרש גדול הוא באג**, ובדרך כלל
   הסיבה היא היסט שעון שגוי או ערך `--spread-points` לא ריאלי.

מה שאסור להתעלם ממנו: אם הסימולציה מראה יתרון והבוט לא, הבעיה היא כמעט
תמיד עלויות ביצוע שלא נלקחו בחשבון, לא באג בלוגיקה.
