# סרטון תדמית — 9:16

סרטון תדמית מונפש (1080×1920, 30fps, ~20 שניות) שנבנה כדף HTML ומרונדר לקובץ MP4
פריים־אחר־פריים. כל הטקסטים, הצבעים והתזמונים יושבים בקובץ אחד — `content.json` —
כך שהחלפת תוכן היא עריכת JSON והרצה מחדש, בלי לגעת בעיצוב.

## התחלה מהירה — להריץ על האתר האמיתי

דרוש Node 18+ בלבד. שלוש פקודות:

```bash
git clone -b claude/website-promo-video-aler3z https://github.com/oriavayou/Ori.git
cd Ori/promo
npm run setup                                    # תלויות + דפדפן (פעם אחת, ~2 דקות)
npm run site -- --url https://iftach-advise.com/
```

הפלט: `promo/out/site-promo.mp4` — פתיח ממותג, האתר האמיתי נגלל, וכרטיס סיום.
הרינדור לוקח כ-3–6 דקות (הוא מצלם כל פריים בנפרד, לא מקליט מסך).

אם יש באנר עוגיות, בועת ווטסאפ או ווידג'ט נגישות שמפריעים בפריים — מסתירים אותם:

```bash
npm run site -- --url https://iftach-advise.com/ --hide ".cookie-banner,.whatsapp-float,#INDmenu-btn"
```

שלוש גרסאות, שלוש פקודות:

| פקודה | מה מקבלים |
| --- | --- |
| `npm run film -- --url https://iftach-advise.com/` | **הסרטון המרכזי** — תסריט, טיפוגרפיה, האתר כהוכחה |
| `npm run tour -- --url https://iftach-advise.com/` | סיור בדפים במסגרות מכשיר |
| `npm run site -- --url https://iftach-advise.com/` | האתר האמיתי בגלילה רציפה, בין פתיח לסיום |
| `npm run scroll` | עמוד הגלילה הקולנועי שנבנה כאן |
| `npm run render` | הסרטון הגרפי בלבד (בלי צילום האתר) |

```
promo/
  content.json        ← כל התוכן: מותג, סלוגן, סצנות, צבעים, תזמונים
  content.example.json← תבנית ריקה להתחלה מאפס
  scene.html          ← העיצוב וההנפשה (RTL, גופן Rubik מוטמע)
  fonts.css           ← Rubik (עברית + לטינית) מוטמע כ־base64
  site/index.html     ← עמוד הגלילה הקולנועי (GSAP + ScrollTrigger + SplitText + Lenis)
  site/film.html      ← העריכה המרכזית: תסריט + כיוון אמנותי
  site/tour.html      ← עריכה חלופית: מעברים בין דפי האתר
  tools/render.mjs    ← מרנדר את הסצנה ל־MP4
  tools/site-promo.mjs← מצלם את האתר האמיתי ועוטף אותו בפתיח וסיום
  tools/lib.mjs
  tools/build-fonts.mjs
  out/                ← הפלט של הרינדורים (לא נשמר בגיט)
```

## הרצה

```bash
cd promo && npm run setup     # פעם אחת
npm run render                # רינדור מלא → promo/out/promo-9x16.mp4
npm run draft                 # טיוטה מהירה בחצי רזולוציה
```

הכלים מוצאים את ffmpeg לבד (דרך `ffmpeg-static` שמותקן עם התלויות). אם מעדיפים
ffmpeg אחר: `FFMPEG=/usr/bin/ffmpeg npm run render`.

### דגלים שימושיים

| דגל | מה זה עושה |
| --- | --- |
| `--scale 0.5` | רינדור טיוטה מהיר בחצי רזולוציה |
| `--stills 0,5,9,14,18` | שומר תמונות סטילס בזמנים האלה במקום וידאו (בדיקה מהירה של עיצוב) |
| `--content path.json` | קובץ תוכן אחר (למשל גרסה לפייסבוק מול גרסה לאתר) |
| `--out path.mp4` | נתיב פלט |
| `--format png` | פריימים ללא דחיסה — איכות מקסימלית, איטי יותר |
| `--fps 60` `--duration 30` | דריסה של התזמון מ־`content.json` |

## הסרטון המרכזי — `film`

סרטון עם **תסריט**: הטקסט נושא את המסר, והאתר מופיע בין המשפטים כהוכחה — לא
כנושא. אורך ~35 שניות, קצב איטי ומכוון, עם רגע אחד מהיר במכוון (שלוש המילים של
תחומי הייעוץ) שמדגיש כמה שאר הסרטון נושם.

```bash
npm run film -- --url https://iftach-advise.com/ --pages "/,/about,/process,/contact"
```

**הכיוון האמנותי** (ב-`site/film.html`): רקע דיו כמעט-שחור, טיפוגרפיה בשנהב חם,
צבע הדגשה אחד — זהב עמום. בלי גרדיאנטים על טקסט, בלי זכוכית, בלי ניאון. הגרפיקה
היחידה החוזרת היא **קו** שרץ לאורך כל הסרטון: מתחיל מקווקו וקופצני (כמו גרף שוק
עצבני) ומתיישר בהדרגה לעקומה עולה ורגועה עד הסיום — הוא הטיעון של הסרטון בצורה
גרפית.

**התסריט נמצא בראש הקובץ** ב-`site/film.html`, במערך `SCRIPT`. כל אובייקט הוא
סצנה: `say` (משפט), `plate` (עמוד מהאתר בתוך מסגרת), `burst` (רצף מהיר),
`end` (סיום). `hold` הוא אורך הסצנה בשניות — שם משנים את הקצב.

## הסיור בדפים — `tour`

זה הכלי ה"קולנועי" מבין השלושה. הוא מצלם כל דף באתר בנפרד (במסך טלפון ובמסך
דסקטופ), ואז מרכיב מהם **עריכה**: כרטיס פתיחה → דף אחרי דף, כשלכל דף כניסה אחרת
(עלייה, החלקה תלת-ממדית, טילט, זום-אין) והדף עצמו נע בתוך מסגרת המכשיר → רגע שבו
כל הדפים עפים יחד לרשת אחת → כרטיס סיום.

```bash
npm run tour -- --url https://iftach-advise.com/
```

גרסה ראוותנית יותר: כל דף בתורו בתוך מסגרת מכשיר, עם כניסה שונה לכל אחד.

שני העריכות מתבססות על אותם צילומים. הכלי מגלה את הדפים לבד מהקישורים בתפריט —
כדאי לבחור ידנית ולהשמיט עמודים משפטיים:

| דגל | מה זה עושה |
| --- | --- |
| `--pages "/,/about,/contact"` | בדיוק הדפים האלה, בסדר הזה |
| `--max 5` | כמה דפים לקחת בגילוי אוטומטי (ברירת מחדל 4) |
| `--hide ".cookie,#chat"` | להסתיר אלמנטים לפני הצילום |
| `--tall 7000` | חיתוך דפים ארוכים במיוחד (בפיקסלים) |
| `--out path.mp4` | נתיב פלט |

הצילומים נשמרים ב-`promo/shots/` יחד עם `shots.json` (מניפסט: נתיב, כותרת, כותרת
ראשית וגדלים). אפשר לרנדר מחדש בלי לצלם שוב:

```bash
node tools/render.mjs --page site/tour.html --data promo/shots/shots.json --out promo/out/tour-9x16.mp4
```

התזמון של העריכה נמצא בראש הסקריפט ב-`site/tour.html` (`const T = {...}`) — שם
משנים אורך של כל שוט, של הפתיח ושל רגע הרשת.

## עמוד הגלילה הקולנועי → סרטון

`site/index.html` הוא עמוד נחיתה מונפש בגלילה: כותרת שנחשפת אות-אות מאחורי מסכה,
שכבות פרלקס, כרטיסים שנערמים, סקשן מוצמד (pinned) שבו השלבים נכנסים אחד-אחד,
וטיקר שנע עם הגלילה. אותו קובץ הוא גם מקור הסרטון:

```bash
npm run scroll        # → promo/out/promo-scroll-9x16.mp4
```

לעמוד שני מצבים. במצב רגיל רצה גלילה חלקה (Lenis) על לולאת ה-ticker היחידה של GSAP,
והחשיפות נכנסות בעקומת ease-out. בהוספת `?render=1` הגלילה החלקה מכובה, כל תנועה
שתלויה בשעון מוחלפת בתנועה שתלויה במיקום הגלילה, והעמוד חושף `window.__renderSeek(y)`
— כך שכל פריים בסרטון יוצא זהה בכל הרצה. גם `prefers-reduced-motion` מכובד: מי
שביקש פחות תנועה מקבל את העמוד סטטי ומלא.

לגרסה שיתופית בקובץ אחד (גופנים מוטמעים, ספריות מ-CDN):

```bash
npm run artifact      # → site/artifact.html
```

## סרטון של האתר עצמו

`site-promo.mjs` מפיק סרטון שמראה את האתר האמיתי — לא גרפיקה שמדמה אותו:

```
[ כרטיס פתיחה ] ← [ האתר האמיתי, נגלל ] ← [ כרטיס סיום ]
```

```bash
node promo/tools/site-promo.mjs --url https://iftach-advise.com/
```

האתר נטען ברוחב של מסך טלפון (430px) ובצפיפות פיקסלים גבוהה, כך שמצולם הלייאאוט
המובייל האמיתי והפלט יוצא בחדות מלאה של 1080×1920. לפני הצילום הכלי גולל פעם אחת
לאורך כל הדף כדי להעיר תמונות ואנימציות שנטענות בגלילה.

| דגל | מה זה עושה |
| --- | --- |
| `--url` | הדף לצילום — `https://…` או `file:///…` לעותק שמור |
| `--scroll 13` | כמה שניות נמשכת הגלילה לאורך הדף |
| `--hold-top` / `--hold-end` | עצירה בראש הדף ובסופו |
| `--css-width 432` | רוחב הלייאאוט שמצולם (למשל `1280` לגרסת דסקטופ) |
| `--hide ".cookie,#chat"` | הסתרת באנר עוגיות, בועת ווטסאפ, ווידג'ט נגישות |
| `--intro intro,hook` / `--outro cta` | אילו סצנות מ־`content.json` יהיו הפתיח והסיום |
| `--no-overlay` | בלי שבב המותג ופס ההתקדמות מעל האתר |

## עריכת התוכן

`content.json` הוא מה שעורכים:

- `meta` — רזולוציה, קצב פריימים, אורך הסרטון ונתיב הפלט.
  לפורמט מרובע: `1080×1080`; ל־16:9: `1920×1080`.
- `theme` — `bg` רקע, `ink` טקסט, `muted` טקסט משני, ו־`c1`/`c2`/`c3` צבעי המותג
  (מהם נבנים כל הגרדיאנטים).
- `brand` — שם, סמל (אות או אימוג'י) וסלוגן.
- `scenes` — רשימת סצנות לפי סדר, לכל אחת `start` ו־`end` בשניות.

סוגי סצנות נתמכים:

| `type` | שדות | מה מופיע |
| --- | --- | --- |
| `intro` | — | לוגו מסתובב, שם המותג באנימציית אותיות, סלוגן |
| `hook` | `kicker`, `lines[]`, `highlight` | משפט פתיחה גדול; `highlight` מודגש בגרדיאנט |
| `features` | `kicker`, `items[{icon,title,text}]` | כרטיסי יתרונות שנכנסים בהדרגה |
| `stats` | `kicker`, `items[{to,suffix,label}]` | מספרים שרצים כלפי מעלה |
| `points` | `kicker`, `items[]` (מחרוזות) | רשימת נקודות עם וי — בלי מספרים |
| `cta` | `title`, `url`, `button`, `note`, `disclaimer` | קריאה לפעולה מסכמת; `disclaimer` הוא שורת אותיות קטנות בתחתית |

הסצנות מצטלבות אוטומטית (כל אחת מתחילה קצת לפני שקודמתה מסתיימת), והפס העליון
מתמלא לאורך כל הסרטון — כך שכדאי לשמור על `end` של הסצנה האחרונה שווה ל־`meta.duration`.

## איך זה עובד

`scene.html` מונפש באנימציות CSS רגילות. בזמן רינדור, `render.mjs` מפעיל Chromium,
מקפיא את כל האנימציות (`animation-play-state: paused`) ואז מזיז כל אחת מהן לזמן
מדויק (`animation.currentTime`) לפני כל צילום מסך. הפריימים נשלחים ישירות ל־ffmpeg
בצינור, בלי לכתוב אלפי קבצים לדיסק. התוצאה דטרמיניסטית: אין פריימים שנפלו ואין
תלות במהירות המכונה.

בזכות זה אפשר גם פשוט לפתוח את `scene.html` בדפדפן (דרך שרת מקומי, למשל
`npx http-server promo`) ולראות את הסרטון רץ בזמן אמת בזמן שעובדים על העיצוב.

## מה אין כאן

אין פס קול. אם רוצים מוזיקת רקע, מוסיפים אותה בשלב אחרון:

```bash
ffmpeg -i promo/out/promo-9x16.mp4 -i music.mp3 -shortest \
  -c:v copy -c:a aac -b:a 192k promo/out/promo-9x16-audio.mp4
```
