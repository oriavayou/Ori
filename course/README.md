# קורס פרסום AI — חומרי הפקה

מבנה קבוע לכל אחד מעשרים השיעורים:

```
course/lesson-NN/
  script.html            תסריט מתוזמן: ביטים, VO, טקסט על המסך, הנחיות ויזואל, שער מעבר
  assets-*.html          חבילת נכסים: מה מייצרים לכל שוט, עם פרומפטים מוכנים
```

הקבצים הם דפי HTML עצמאיים — נפתחים בדפדפן כמו שהם, וגם מפורסמים כ‑Artifacts
לצפייה ולשיתוף. אין תלות בבנייה או בהתקנה.

## המותג של הקורס

כל פרסומת שמופיעה על המסך בשיעורים נבנית ממותג הדגמה בדיוני — **18**, תרכיז
קולד ברו. הערכה המלאה נמצאת ב‑`lesson-01/assets-brand-18.html`. הסיבה כפולה:
אנחנו הבעלים של כל פריים, ואפשר לייצר בכוונה גם את הגרסה הגרועה שמדגימה כשל.

## סדר עבודה על שיעור

1. `script.html` — נסגר ראשון. בלי תסריט אין מה לייצר.
2. `assets-*.html` — keyframes כתמונות, ואז הנפשה מהתמונה.
3. הקראה, הקלטות מסך, עריכה.

טקסט עברי לא נוצר בתוך מנוע התמונה אלא נוסף בעריכה.
